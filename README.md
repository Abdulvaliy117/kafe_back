# Осман Кафе — API

Бэкенд сайта заказа еды для Осман Кафе (Ош). Django + DRF. Меню и настройки
редактируются в админке, заказы сохраняются и превращаются в готовый текст для
WhatsApp.

## Стек

- Django 6.1, Django REST Framework
- drf-yasg (Swagger), django-cors-headers, whitenoise
- SQLite локально, Postgres (Supabase) на проде
- Supabase Storage (S3) для фото на проде
- gunicorn на проде

## Локальный запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # проверьте WHATSAPP_NUMBER
python manage.py migrate
python manage.py seed_menu    # заготовка меню (10 категорий, 42 блюда)
python manage.py createsuperuser
python manage.py runserver
```

- Админка: http://127.0.0.1:8000/admin/
- Swagger: http://127.0.0.1:8000/api/v1/swagger/

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `SECRET_KEY` | Секрет Django (на проде обязателен) |
| `DEBUG` | `True` локально, `False` на проде |
| `ALLOWED_HOSTS` | Домены через запятую |
| `CSRF_TRUSTED_ORIGINS` | Домены фронтенда (https) |
| `CORS_ALLOWED_ORIGINS` | Домены фронтенда через запятую |
| `WHATSAPP_NUMBER` | Номер кафе, только цифры |
| `DELIVERY_FEE` | Стоимость доставки по городу, сом |
| `FRONTEND_URL` | Адрес витрины — для кнопок «Открыть сайт» и «Пульт менеджера» в шапке админки |
| `DATABASE_URL` | Postgres-строка (Supabase) |
| `SUPABASE_S3_*` | Хранилище фото (bucket, endpoint, region, ключи, public url) |

## API

| Метод | Адрес | Описание |
| --- | --- | --- |
| GET | `/api/v1/menu/` | Категории с блюдами |
| GET | `/api/v1/site/` | Инфо о кафе, WhatsApp, доставка |
| POST | `/api/v1/orders/` | Создать заказ → возвращает `whatsapp_url` |
| GET | `/api/v1/orders/` | Список заказов (только staff). Фильтры: `status`, `delivery_type`, `is_spam`, `date` |
| PATCH | `/api/v1/orders/{id}/` | Сменить статус (только staff) |
| POST | `/api/v1/auth/token/` | Логин менеджера → токен (`Authorization: Token …`) |

Сервер сам пересчитывает суммы по БД и не доверяет суммам с клиента. Есть
honeypot-поле и троттлинг 10 заказов/минуту.

## Для менеджера

Рабочий инструмент менеджера — **пульт на фронтенде `/manage`** (см. репозиторий
`osman_cafe_front`): вход по логину/паролю сотрудника, вкладки статусов, смена
статуса в один клик, сводка смены, автообновление. Для входа заведите пользователя
в админке с галочкой «Статус персонала».

В шапке админки есть кнопки **«Открыть сайт»** и **«Пульт менеджера»** —
они ведут на витрину и пульт (адрес берётся из `FRONTEND_URL`).

Админка `/admin/` (Django) — для наполнения меню/контактов и как запасной пульт:

- **Номера заказов по дням** («№12 от 18.10.2026»): счётчик сбрасывается в полночь
  по Asia/Bishkek, спам номер не занимает. Внутри у заказа остаётся `id`.
- В списке заказов: цветные статусы, время, суммы, фильтры (в т.ч. «Спам»),
  поиск по имени/телефону/номеру, иерархия по датам.
- **Быстрые кнопки** «В работу» / «Готово» прямо в строке (без открытия заказа).
- **Массовые действия**: ✅ Принять в работу, 🏁 Выполнено, ❌ Отменить, 🚫 Спам.
- **Сводка за смену** сверху: новых заказов и выручка за сегодня.
- **Автообновление**: страница сама опрашивает новые заказы (раз в 25 c), показывает
  баннер и подаёт звуковой сигнал; заголовок вкладки меняется на «🔔 N новых».
- Кнопка «Написать в WhatsApp» открывает чат с клиентом и готовым чеком.

## Деплой (Render + Supabase)

1. **Supabase** → New Project. Скопируйте Connection string
   (`postgresql://postgres.<project>:<password>@<host>:5432/postgres`).
2. **Render** → New → Blueprint → репозиторий `osman_cafe` (подхватит `render.yaml`).
   Задайте `DATABASE_URL` и (для фото) `SUPABASE_S3_*`, при желании `DJANGO_SUPERUSER_*`.
3. После первого деплоя откройте `https://<ваш-сервис>.onrender.com/admin/`.

Фото: на Render диск эфемерный, поэтому для картинок обязателен Supabase Storage
(публичный bucket + Project Settings → S3 → ключи). Без него фото пропадут при
передеплое.

## Наполнение меню

`seed_menu` создаёт заготовку. `--reset` пересоздаёт меню, `--if-empty` (используется
в `build.sh`) ничего не делает, если блюда уже есть, — правки кафе не затираются.
